Agentic mode asks clarifying questions whenever a choice would change the result. Turn this on to make it ask at least once before starting any new task. Answers are remembered as canon, so it never asks the same thing twice.

Lets file tools reach anywhere your user account can read, not just the allowed roots. Shell commands still run, so only enable this if you are comfortable with that.

Auto-run safe commands lets Aether work without interrupting you: it runs your project's code, edits its files, installs packages and uses git freely. It stops only for things you would want to catch: deleting files (rm, shred), sudo, disk and system commands, writes into system folders, piping a download straight into a shell, and git push / reset --hard / clean -f. Approve one of those with "Always allow" and it will not ask again. Ask every time confirms every command; Never ask runs everything unattended.
